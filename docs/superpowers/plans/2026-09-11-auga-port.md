### Task T8: SmoothRegen HP bar fix [agent]

**Files:** Modify `AugaUnityLib/AugaHealthBar.cs:47-51` (`Start`)

Root cause, traced in code:
- `AugaHealthBar.LateUpdate` calls `FastBar.SetValue(...)` and `SlowBar.SetValue(...)` every frame (`AugaHealthBar.cs:99-105`).
- In `HealthBar.prefab`, `FillFast` is the red fill (color `0.678,0.086,0.086`) with `m_smoothFill: 1`, `m_smoothSpeed: 0.25`, `m_changeDelay: 0.5`. `FillSlow` has `m_smoothFill: 0`, so it snaps to the new value.
- Vanilla `GuiBar.SetValue` re-arms `m_delayTimer = m_changeDelay` on every call where `value > m_value && m_smoothFill` (`assembly_guiutils/GuiBar.cs:73-76`). `LateUpdate` only moves the bar once the timer is ≤ 0 (`:98-115`).
- SmoothRegen heals a little every frame (`SmoothRegenPatches.cs:92-99`, `Character.Heal` per `UpdateStats`), so the timer is re-armed every frame. The red fill never moves, while `FillSlow` runs ahead as the light "pending" layer.
- Vanilla's lump heal every 10 s re-armed it only once, so the bug never showed.
- The fix belongs in Auga (SmoothRegen is correct). Zero the change delay on the smooth-fill bar. Continuous heals then track at up to 25 % of max per second, and big heals still animate.

- [ ] **Step 1: Model check (fails on the current behaviour, passes on the fix).** Save as `E:\DEV\Valheim\Auga\tools\guibar-delay-check.ps1`:
  ```powershell
  Add-Type -TypeDefinition @'
  public static class BarSim {
    // Mirrors GuiBar.SetValue/LateUpdate fill path (assembly_guiutils GuiBar.cs:57-116).
    public static float Run(float changeDelay, int frames) {
      float dt = 1f/60f, max = 100f, value = 50f, smooth = 0.5f, timer = 0f, speed = 0.25f;
      for (int f = 0; f < frames; f++) {
        float nv = value + 0.05f;               // SmoothRegen: +3 HP/s paid per frame
        if (nv > value) timer = changeDelay;    // SetValue re-arms delay (smoothFill)
        value = nv;
        timer -= dt;
        if (timer <= 0f) { float t = value / max; smooth = t > smooth ? System.Math.Min(t, smooth + speed * dt) : t; }
      }
      return smooth * max - value;              // red fill minus real HP
    }
  }
  '@
  $bug = [BarSim]::Run(0.5, 600); $fix = [BarSim]::Run(0, 600)
  if ($bug -gt -29) { throw "model does not reproduce the frozen bar: lag=$bug" }
  if ([math]::Abs($fix) -gt 0.1) { throw "delay 0 still lags: $fix" }
  "OK frozen-lag=$bug fixed-lag=$fix"
  ```
  Run: `pwsh -File E:\DEV\Valheim\Auga\tools\guibar-delay-check.ps1`. Expected: `OK frozen-lag=-30 fixed-lag=0` (approximately).
- [ ] **Step 2: Implement**
